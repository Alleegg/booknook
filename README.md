1. <!DOCTYPE html> (объявление типа документа), <html> (корневой элемент), <head> (служебная информация), <title> (заголовок страницы) и <body> (видимое содержимое). Без них документ не будет считаться валидным HTML5.


2. Изображение вставляется тегом <img src="путь_к_файлу" alt="описание">. Атрибут alt указывать обязательно (хотя технически можно и не указывать, но это плохая практика). Он нужен для доступности сайта для незрячих людей и если изображение не загрузилось, пользователь видит текст вместо него.


3. Внутри тега <head> нужно написать: <link rel="stylesheet" href="styles.css">. rel="stylesheet" говорит, что это таблица стилей href указывает путь к файлу


4. Теги <form> нужны для создания форм, через которые пользователь может отправлять данные на сервер. Например: регистрация, вход, обратная связь, поиск, оформление заказа. Внутрь кладутся поля ввода (<input>, <textarea>, кнопки отправки и т.д.).


5. Каждый элемент на странице - это прямоугольник, который состоит из:

* content (содержимое) - сам текст или картинка

* padding (внутренний отступ) - пространство между содержимым и границей

* border (граница) - рамка вокруг элемента

* margin (внешний отступ) - расстояние от границы до соседних элементов


6. Используется псевдокласс :hover. Например:

```
button {
    background-color: blue;
}
button:hover {
    background-color: darkblue;
}
```


7. Flexbox - для распределения элементов в одну линию (строку или колонку). Удобно для меню, карточек в ряд, центрирования.
CSS Grid - для создания сложных сеток (сетка как в Excel). Позволяет размещать элементы и по строкам, и по колонкам одновременно. Можно делать полноценный макет страницы.


8. Способы выбрать элементы для стилизации:

* *- универсальный (все элементы)

* div - по тегу

* .class - по классу

* #id - по идентификатору

* element element - вложенные элементы

* element, element - перечисление

* element > element - прямые потомки

* element + element - соседние элементы


9. Несколько способов:
```
document.getElementById('id') - по id
document.querySelector('.class') - по CSS-селектору (первый)
document.querySelectorAll('div') - все элементы по селектору
document.getElementsByClassName('class') - по классу
document.getElementsByTagName('div') - по тегу
```


10. Семантические теги - это теги, которые несут смысловую нагрузку и понятны не только браузеру, но и разработчику. Например: <header> (шапка), <nav> (навигация), <main> (главное содержание), <article> (статья), <section> (раздел), <footer> (подвал), <aside> (боковая панель).
